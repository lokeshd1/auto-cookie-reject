# Chrome Web Store Listing

## Extension Name
Auto Cookie Reject

## Short Description (132 characters max)
Automatically reject cookie consent popups and banners. Privacy-first, runs 100% locally.

## Detailed Description

**Tired of clicking "Reject All" on every website?**

Auto Cookie Reject automatically handles cookie consent popups so you don't have to. Unlike other tools that just hide banners, this extension actually clicks the reject button for maximum privacy.

**Features:**

- Automatically rejects cookies on 11+ major consent platforms
- Instantly hides cookie banners while processing
- Works on all websites
- Per-site enable/disable control
- Tracks how many banners you've avoided
- 100% local - no data sent anywhere

**Wide Compatibility:**

Works with 11+ cookie consent platforms used across the web, including those deployed by major news sites, e-commerce stores, and enterprise software. Also handles generic banners that don't use a named platform.

**Privacy First:**

- Zero data collection
- No analytics
- No external servers
- All processing happens in your browser
- Open source code you can audit

**How It Works:**

1. CSS instantly hides cookie banners
2. JavaScript detects which consent platform is used
3. Automatically clicks "Reject All" or "Only Necessary"
4. Removes scroll-blocking overlays

**Permissions Explained:**

- Storage: Save your settings locally
- All URLs: Detect cookie banners on any website

https://github.com/lokeshd1/auto-cookie-reject
